# Farm Game

More like a Ranch game

## Goal

Small 2D pixel-art animal sandbox / barn game.

## Platforms

- PC
- Tablet
- Mobile

## Architecture

- GameManager: game loop and world management
- GameObject: base runtime object
- Animal: animal behavior
- UIManager: HTML UI Loader
- AssetsLoader: Asset Loader for resue
- SpriteAnimation: Sprite processor

## Current animals

- Chicken
- Duck
- Dog
- Sheep

## Current gameplay

- Animal wandering
- Selection/hover
- Properties panel
- Store
- Buying/selling
- Resource bar
- Animal naming
- Dog targeting animals
